# AutoFatre

Repo install URL:

```text
https://raw.githubusercontent.com/irimsky/DalamudPlugins/refs/heads/main/manifest.json
```

AutoFatre 是一个面向《最终幻想 XIV》的 Dalamud 自动化插件，用于自动执行战斗型 FATE 流程。项目目前主要维护国服客户端，也欢迎其他地区的本地化贡献。

插件负责流程控制、移动、传送和目标管理，不负责施放职业技能。请同时运行能够处理当前目标的战斗或职业循环插件。

## 功能

- 在当前地图持续循环可执行的 FATE。
- 指定一个或多个同地图 FATE 作为目标；目标尚未出现时，可以等待或继续处理其他 FATE。
- 按地图顺序执行自定义预设，并根据 FATE 完成次数、背包物品数量和指定 FATE 等条件切换地图。
- 支持普通怪物消灭、讨伐 BOSS、收集、防御和护送 FATE。
- 自动处理跨地图传送、都市传送网中转、坐骑、飞行、禁飞区和地面导航。
- 只对未接战目标进行一次地面导航接近，包括未开战的普通怪物、BOSS 和破坏目标；共用“战斗接近距离”设置（默认 3 yalms）。已在本批/客户端接战名单中或正在攻击玩家的目标只选中、不靠近，靠近途中接战也立即停止导航。到达距离或本次导航终点、向该目标施放攻击读条后结束接近；召唤伙伴、治疗和自身增益等非攻击读条只暂停，读条结算后继续未完成的靠近。走远或躲技能不会触发自动拉回；同一次导航不追随目标移动重发路径。
- 处理等级同步、战斗陆行鸟伙伴、战后清场和导航失败恢复。
- 支持死亡后接受其他玩家复活，或等待超时后返回复活点并恢复任务。

## 依赖

| 插件 | 用途 |
| --- | --- |
| **vnavmesh** | 地面导航、飞行导航和路径查询 |
| **Lifestream** | 以太之光和都市传送网传送 |
| **BossMod** 或 **BossMod Reborn** | 战斗目标和战斗行为处理 |
| **Wrath Combo** 或 **Rotation Solver Reborn** | 职业技能循环和实际技能施放 |

[TextAdvance](https://github.com/NightmareXIV/TextAdvance) 是可选依赖，可协助推进 FATE 开启和收集交付对话。未安装时，插件会使用原生对话流程。

战斗相关需要各安装一类插件：前一类负责战斗中的目标和行为，后一类负责当前职业的技能循环。

## 快速开始

1. 在 Dalamud 的自定义插件仓库中添加上方的 Repo install URL。
2. 确认 vnavmesh、Lifestream、目标/战斗行为插件和职业循环插件均已加载并正常运行。
3. 使用 `/autofatre` 或 `/af` 打开主窗口。
4. 在“选择模式”中选择运行模式，并完成地图或 FATE 配置。
5. 点击启动/停止旁的“打开设置”、主窗口标题栏右上角齿轮、悬浮窗齿轮或 Dalamud 插件安装器的设置按钮，按分类调整飞行、战斗陆行鸟、死亡恢复、音效提醒和 FATE 黑名单。
6. 选择“开始”，先在低风险场景观察传送、导航、落地、等级同步和战斗目标是否符合预期。

## 命令

命令前缀支持 `/autofatre` 和简写 `/af`。

| 命令 | 作用 |
| --- | --- |
| `/autofatre`、`/autofatre ui` | 打开主控制面板 |
| `/autofatre config`、`/autofatre settings` | 打开设置窗口（也可点击 Dalamud 插件安装器中的设置按钮） |
| `/autofatre start` | 启动自动化 |
| `/autofatre pause` | 暂停自动化并停止插件发起的移动 |
| `/autofatre retry` | 从暂停或可恢复故障状态重新校验并继续 |
| `/autofatre stop` | 停止自动化 |

## 运行模式

主窗口保留“运行”和“选择模式”两个页签。独立设置窗口按左侧分类显示界面、伙伴、移动与导航、战斗、迷失目标、死亡恢复、FATE 黑名单、音效提醒和诊断，每类保留独立滚动位置。

### 单地图循环

在指定地图持续选择并完成可用 FATE。

### 指定 FATE

选择一个或多个同地图 FATE 作为目标。插件会按配置等待目标出现或处理其他符合条件的 FATE；完成指定目标后结束当前目标流程。

### 自定义预设序列

按顺序执行多个地图。每张地图可以设置 FATE 完成次数、背包物品数量和指定 FATE 等停止条件，列表可以在完成后停止，也可以循环执行。

也可以单独勾选“当前地图无 FATE”，在滑块中选择 3～10 秒（默认 5 秒）；当前地图持续没有任何 FATE 达到该时间后进入下一地图。此条件与其他停止条件互斥，勾选时暂时停用其他条件。各地图取消条件后保留已填数据，重新勾选会恢复原值。黑名单、准备中和不可执行的 FATE 也算地图上有 FATE；暂停、死亡、切图及加载期间不计时。

预设地图还可以配置进入地图后自动召唤的宠物物品和自动装备的武器物品。

设置中的音效提醒可分别选择游戏内置音效：进入 FATE 时圈内已有其他玩家会提醒一次，之后有新玩家进入也提醒；双色宝石数量达到设置阈值或更高时提醒一次，消费降到阈值以下后再次达到阈值可重新提醒。双色宝石阈值范围为 1～1500，默认 1500。两项默认“无音效”，需要启用提醒并选择音效才会播放。

## FATE 处理

等待开启的 FATE 从选中起保留 5 分钟的准备时间，涵盖赶路、等待开启 NPC 出现和开启交互，不再因 NPC 延迟出现而在 90 秒后放弃。NPC 出现后照常靠近、交互；单次对话及导航停滞保护不变。

| 类型 | 处理方式 |
| --- | --- |
| 消灭普通怪物 | 按当前职业的主动拉怪上限分批处理目标，战斗技能由外部战斗插件执行。 |
| 讨伐 BOSS | 持续优先选择当前 FATE 中生命值最高的可攻击目标。 |
| 收集物品 | 导航到收集对象，取得物品后前往交付目标；受到攻击时先处理战斗目标。 |
| 防御 | 以 FATE 中心作为安全范围，优先处理正在攻击防御目标的敌人。 |
| 护送 | 追踪护送目标并优先处理正在攻击护送目标的敌人；没有可攻击目标时保持在目标附近。 |

设置中的坦克、输出、治疗拉怪上限分别独立配置，范围均为 1～6 只，默认分别为 4、3、4 只；近战、物理远程和魔法输出共用输出设置。该上限只限制主动拉怪，额外攻击者仍可能加入战斗。普通怪物 FATE 进度达到 80% 后不再半数补怪，达到 90% 后主动拉怪上限降为 1。

勾选“优先击杀迷失目标”后，可分别设置少女和迷失者的触发阈值：FATE 剩余时间不低于对应阈值才会开始优先击杀，默认分别为 180 秒、240 秒，范围 0～600 秒，0 表示不限制。已锁定的目标会继续击杀至死亡或消失，不因剩余时间低于阈值而中断。

「阻止新殖民」（FATE 498）的「违法砍伐的木材」按破坏目标优先锁定，不再作为普通怪分批拉取；鸟人仍属于讨伐目标。沿用破坏流程：一个对象处理完后若接战至少 5 只，先清空整批再继续破坏。

幽谷药师——黎明药达奇希奥（FATE 616）中，坦克和近战输出会先完成原有战前非 FATE 清怪环节，再步行至黑衣森林东部林区 `(32.0, 14.0)` 附近的可站立地面，到达后才进行等级同步和进入 Boss 战斗。每次重新同步都会先检查此站位；无法到达时不会跳过检查直接同步。远程输出和治疗不执行此特殊站位，战斗中不会因躲技能走远而持续拉回。

此位置使用游戏内地图 X/Y 坐标，换算为世界 X/Z 后按玩家所在高度寻找附近可行走地面，不使用旁边更高的石头作为站位。

FATE 完成后，插件会先清理仍以本地玩家为目标的战斗 NPC，脱战后再前往下一个目标。

完成计数采用参与后的状态转换，每次活动只计一次；不会仅因为 FATE 从列表消失就算成功。日志同时记录独立的成功奖励包计数及 Medal（金／银／铜评价），每次状态完成或奖励包结算都会输出两套累计数和差值；两种事件可能先后到达，因此瞬时差值不等于最终漏计。奖励包统计目前只用于对照，不改变任务停止条件。

普通拉怪候选允许位于 FATE 半径外 5 码。已接战至少 2 只时，如果最近的剩余可拉目标距离达到 25 码，就先清空当前批次，再继续拉怪；该批次期间不执行半数补怪。防御、护送任务中为友方 NPC 转移仇恨的拉怪不受此距离规则限制。

所有 FATE 战斗期间，角色与中心的水平距离达到“FATE 半径 − 3 码”时会立即取消当前目标、停止原导航，并步行返回 FATE 中心附近的可站立地面，不再停在某个半径百分比位置。中心附近找点和实际水平到达范围均不超过 3 码；到达后恢复原流程，必要时先重新同步。

## 传送、导航与恢复

- 跨地图时，从角色已解锁的入口中选择目标，并交给 Lifestream 执行传送。
- 目标地图没有合适的直达入口时，尝试通过都市传送网中转。
- 启用飞行后，在满足条件时上坐骑并飞行导航；接近 FATE 后确认落地，再下坐骑并进行等级同步。
- 禁飞区支持地图坐标两点形成的矩形；当前加入南萨纳兰 `(27.4, 21.5)` 到 `(36.2, 17.2)` 的试验区域。该区域从外部飞入时先前往指定平面落地点 `(27.4, 20.9)`，由 vnavmesh 查询该位置的可站立高度后再下降，之后步行到原目标；未配置落地点的禁飞区继续由 vnavmesh 搜索当前位置附近的最近可达地面。
- 落地 12 秒仍未成功时，在 FATE 范围内尝试约 10 码的水平偏移，查询附近可行地面并导航过去重新落地；小范围 FATE 会缩小偏移距离。
- 禁飞区使用地面导航；未使用指定落点时，离开禁飞区后在条件稳定时恢复飞行；使用指定落点后，本次导航保持地面模式直到原目标。
- 导航、传送或依赖暂时不可用时进入恢复流程；FATE 恢复次数耗尽后只记录失败、不添加冷却，重新执行当前地图的传送路线，进图后从当前位置重新选择 FATE。没有直达水晶的地图继续沿用都市传送网中转路线。
- 若战斗状态残留但没有可见目标，先跑离并等待脱战，再继续后续流程。
- 角色死亡后，可以自动接受其他玩家复活；启用自动返回时，等待时间结束后返回复活点并重新验证任务。

## 注意事项

- 这是一个会自动移动、传送、交互和参与战斗的插件。首次使用或修改配置后，请先观察完整流程。
- 请确保角色拥有目标地图的传送权限、坐骑和飞行权限，以及足够的传送和伙伴相关资源。
- 没有可用的目标/战斗行为插件或职业循环插件时，角色可能无法建立仇恨或完成 FATE。
- FATE 支持范围取决于当前客户端数据和插件实现；不支持的类型会显示排除原因并跳过。
- 游戏更新可能改变 Dalamud、依赖插件或游戏界面行为。
